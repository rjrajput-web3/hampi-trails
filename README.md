# Hampi Trails — Rooms & Dormitories near Anjanadri Hills, Hampi

Official website for Hampi Trails, a stay near Anjanadri Hills in Hanumanahalli, Gangavathi, Karnataka 583227.

Double rooms and dormitories with balconies, patios and a garden, mountain and landmark views, an on-site restaurant, free WiFi and free private parking.

## View locally

Single-page static site — open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server
```

Note: the hero image is embedded in the HTML as a base64 data URI, which is why `index.html` is large (~14 MB).
